# Advanced Machine Learning Lab

This repository contains practical implementations and experiments covering advanced machine learning concepts using Python.

## Topics Covered

- Neural Network Implementation
- Custom Activation and Loss Functions
- Ensemble Learning
- Random Forest
- AdaBoost
- CatBoost
- Reinforcement Learning – Q-Learning
- Support Vector Machines (SVM)
- Hyperparameter Tuning
- Model Evaluation

## Technologies and Libraries

- Python
- TensorFlow
- Scikit-learn
- NumPy
- Pandas
- Matplotlib



## Purpose

The objective of this lab work is to understand, implement and evaluate advanced machine learning algorithms through practical experimentation.
